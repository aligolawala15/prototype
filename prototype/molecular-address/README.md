# Molecular Address

Computational research prototype for selective retrieval from simulated DNA archives.

## Milestone 1

Current objective:

Digital file
-> bytes
-> binary
-> A/C/G/T DNA representation
-> binary
-> bytes
-> reconstructed file

DNA mapping:

00 -> A
01 -> C
10 -> G
11 -> T

Milestone 1 does NOT simulate:
- molecular synthesis
- physical DNA
- sequencing
- random access
- sequencing errors
- integrity verification
- reconstruction under noise

Those will be added only after this foundation passes verification.
